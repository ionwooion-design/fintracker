# Патч: уведомления о лимите + порядок разделов в Настройках

## Установка
Распаковать поверх корня проекта.

```bash
unzip -o fintracker-limit-alerts-patch.zip
npm install sonner@2.0.7   # если ещё нет в node_modules
```

## Порядок разделов «Настройки»
1. Профиль
2. Бюджетный период
3. Фиксированные события
4. Повторяющиеся
5. Категории расходов
6. Категории доходов
7. Уведомления о лимите
8. Опасная зона — **свёрнута по умолчанию** (кнопка «Показать»)

## Файлы
| Путь | Действие |
|------|----------|
| `src/components/finance/budget-alerts.tsx` | новый |
| `src/routes/__root.tsx` | Toaster |
| `src/routes/index.tsx` | BudgetAlerts + notify |
| `src/routes/settings.tsx` | порядок + опасная зона |
